这块卡片为什么不出方块？

它带有 trailAnimationIgnore。鼠标在卡片内移动时， 事件目标会命中这个子树，组件直接返回。

只有空白背景会触发

纯文本叶子节点、<a>、<button> 以及 ignore 子树都会被跳过，避免方块盖住内容。

方块从哪来？

页面底部只有一个固定层：10 个 20×20 的 div 循环复用。 颜色和字符每次随机，DOM 数量恒定。

how-it-works/

四步，二十行核心逻辑

  1. 区域 opt-in

    只给 .trailAnimationArea 绑定 mousemove； 命中 .trailAnimationIgnore 子树时直接返回。

  2. 光标量化到网格

    用视口坐标取整，而不是元素内坐标；方块是 fixed 定位， 所以滚动时网格仍然对齐。 

    const x = Math.floor(event.clientX / grid) * grid;
const y = Math.floor(event.clientY / grid) * grid;
if (x === lastX && y === lastY) return;

  3. 池化复用 + 随机外观

    10 个方块轮流使用；每次激活随机取一个品牌色和一个 ASCII 字符， 30% 概率是空格（纯色块）。

  4. CSS 负责生命周期

    激活时加 is-active，内部色块 scale(0) → scale(1)；定时器移除 class 后自动缩回。 

    .trail-block__color {
  transform: scale(0);
  transition: transform .1s cubic-bezier(.3,.41,.04,1.01);
}
.trail-block.is-active .trail-block__color { transform: scale(1); }

原站还监听 River 标题，并在 prefers-reduced-motion: reduce 时完全不渲染。 本示例同样支持；拖动上方参数可对比不同网格和池大小。
